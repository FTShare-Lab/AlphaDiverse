# 数据接口

[返回项目主页](../README.md) · [English](data_EN.md)

`--data` 支持单个 Parquet 文件、包含 Parquet 分区的目录，或包含 `base_panel/` 子目录的缓存目录。命令行日期区间包含起止日期，读取范围从 inner 开始日至 outer 结束日。预计算的滚动特征应已使用足够的历史数据完成预热；研究中新生成的滚动因子在窗口起始阶段可能存在缺失值。

输入目录内的分区必须互不重叠，每个 `date`—`symbol` 只能有一条记录。若上游缓存保留了历史刷新快照，应按其清单选择当前有效分区，放入独立目录后再传入；不能把多个版本一起递归加载。程序会拒绝重复记录，不会自动去重。

数据字段约定如下：

| 字段                                   | 含义                                                                           |
| -------------------------------------- | ------------------------------------------------------------------------------ |
| `date`                               | 信号形成日期，格式为 YYYY-MM-DD                                                |
| `symbol`                             | 沪深股票代码，如`600000.XSHG`、`000001.XSHE`；也接受 `.SH`、`.SZ` 后缀 |
| `open`、`high`、`low`、`close` | 日频价格，复权口径须保持一致                                                   |
| `volume`                             | 成交股数                                                                       |
| `turnover`                           | 成交额，不是换手率                                                             |
| 基础因子与可用特征列                   | 预计算的、满足因果约束的日频/分钟频量价特征                                    |
| `label_<market>_excess_ret_1d`       | 下一交易日开盘至再下一交易日开盘的股票收益，减去同区间对应市场基准收益         |
| `in_<market>`                        | 各信号日期对应的历史成分标记，布尔值                                           |
| `universe_eligible`                  | 可选的预计算可交易标记；未提供时，输入面板须已完成可交易股票筛选               |

对于信号日 t，特征只可使用截至 t 日收盘的信息，一日目标对应 `open(t+1) → open(t+2)`。标签与可交易筛选采用输入数据的既定口径，程序不重新构造或静默修改。数据应包含截至 outer 结束日已成熟的标签，并在准备阶段完成所需的 ST、停牌、涨跌停及上市不足60天股票筛选。系统排除北交所股票。

默认 Level1 包含21个基础量价因子：`ret_1`、`open_close_ret`、`high_low_range`、`close_position`、`vwap`、`vwap_deviation`、`log_turnover`、`log_volume`，九个 K 线形态因子（`KMID`、`KLEN`、`KMID2`、`KUP`、`KUP2`、`KLOW`、`KLOW2`、`KSFT`、`KSFT2`），以及 `OPEN0`、`HIGH0`、`LOW0`、`VWAP0`。通过 `--base alpha20` 可切换到 Alpha20。也可用 `--base-features ret_1 high_low_range close_position log_volume ROC60 STD5 VSTD5 CORR5` 显式指定 Level1 与 Alpha20 的混合子集；该参数覆盖 `--base`，同一列表同时用于 baseline 和最终模型的基础特征，并完整写入 `run.json`。重复列及标签、成分标记等非候选列会被拒绝。基础因子缺失时程序会报错。研究输入仅限支持的量价特征目录，标签、成分标记、指数权重及无关数值列不会作为因子输入。

指数市场须使用逐日历史成分。可通过 `--membership-data` 提供单独的 Parquet 表，包含 `date`、`market`、`component_symbol`；额外的权重列会被忽略。该表覆盖缓存中的成分标记，且必须覆盖所有已加载的观测日期，缺失时不会退回当前成分或静态成分。若省略此参数，面板中的 `in_<market>` 必须已经是正确的逐日成分。`ashare` 使用输入数据中全部符合条件的沪深 A 股。
